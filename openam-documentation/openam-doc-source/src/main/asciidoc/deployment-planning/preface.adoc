[#preface]
== Preface

This guide helps architects, deployers, and project managers choose an OpenAM deployment topology, size it against service objectives, and define what to verify before production. Confirm the compatibility of the OpenAM release, servlet container, Java runtime, and integrations in the xref:../release-notes/index.adoc[Release Notes].

[#who-should-use]
=== Who Should Use This Guide

Choose the path that matches your availability and recovery requirements.

* *Evaluation.* Start with the xref:../getting-started/index.adoc[Getting Started Guide] for a single instance. Use the xref:chap-intro.adoc#chap-intro[integration overview] to choose the application flows to try.
* *Single production site.* Review the xref:chap-topologies.adoc#openam-sites[site topology] and xref:chap-hw-sw-requirements.adoc#chap-hw-sw-requirements[platform and storage requirements]. Use xref:chap-sizing.adoc#chap-sizing[sizing] to verify capacity, including after loss of a node or dependency. Complete the xref:chap-high-level-start.adoc#chap-high-level-start[deployment checklist] before accepting traffic.
* *Multiple sites.* Start with xref:chap-topologies.adoc#multi-sites[the multi-site topology] and decide which services and sessions must survive a site outage, how to route clients on failover, how to handle replication lag, and how to return to normal service. Apply the same sizing and acceptance checks under cross-site traffic and recovery conditions.

For installation and configuration procedures, see the xref:../install-guide/index.adoc[Installation Guide] and xref:../admin-guide/index.adoc[Administration Guide]. Use the xref:../upgrade-guide/index.adoc[Upgrade Guide] to rehearse changes to an existing deployment.
