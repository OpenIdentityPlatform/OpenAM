[#openam-monitoring-using-prometheus]
== OpenAM Monitoring Using Prometheus

[[openam-monitoring-using-prometheus-preface]]
=== Preface

https://github.com/OpenIdentityPlatform/OpenAM[OpenAM] can expose SNMP metrics. To expose these metrics to Prometheus we will use https://github.com/prometheus/snmp_exporter[snmp++_++exporter] tool, provided by the Prometheus community.

To follow the current manual Docker and Docker Compose should be installed

Configuration files located in this project https://github.com/maximthomas/openam-prometheus[https://github.com/maximthomas/openam-prometheus]

Just clone it and run with docker-compose:

[source,bash]
----
git clone https://github.com/maximthomas/openam-prometheus.git
----

[source,bash]
----
cd ./openam-prometheus
----

[source,bash]
----
docker-compose up
----

[[openam-monitoring-using-prometheus-setup-openam-and-snmp-monitoring]]
=== Setup OpenAM and SNMP Monitoring

Open OpenAM URL and create a basic configuration (see xref:quick-start-guide.adoc[OpenAM Quick Start Gude])

Enable SNMP in OpenAM. Login into OpenAM console, goto *Configure -++>++ Global Services -++>++ Monitoring*

image:images/how-to/openam-prometheus/openam-monitoring.png[OpenAM monitoring]

Enable checkboxes *Monitoring Status* and *Monitoring SNMP interface status*

Restart OpenAM instance

[[openam-monitoring-using-prometheus-setup-snmp-exporter]]

Open SNMP exporter URL

http://localhost:9116/

image:images/how-to/openam-prometheus/snmp-exporter.png[SNMP exporter]

Fill the fields: Target: OpenAM hostname and port, for example `openam:8085` Module: SNMP exporter module, for example `openam`

[[openam-monitoring-using-prometheus-setup-prometheus]]
=== Setup Prometheus

If you have an existing prometheus instance add to `prometheus.yml` job `openam` with a target to SNMP exporter host and port:

[source,yaml]
----
  - job_name: "openam"
    params:
      target: ["openam:8085"]
      module: ["openam"]
    metrics_path: /snmp
    static_configs:
      - targets: ["snmp-exporter:9116"]
----

Run Prometheus and check targets:

http://localhost:9090/targets You should see something like this:

image:images/how-to/openam-prometheus/prometheus-target.png[Prometheus target]

Then go to Graph and you will be able to add OpenAM metrics to monitor.

http://localhost:9090/graph

image:images/how-to/openam-prometheus/prometheus-graph.png[Prometheus graph]
