== SSO Configuration: OpenIG as SAML Service Provider for OpenAM

[[sso-configuration-openig-as-saml-service-provider-for-openam-introduction]]
=== Introduction

The SAML 2.0 protocol is the standard for Single Sign-On (SSO) in enterprise environments. In this guide, we will show you how to use OpenIG as a proxy and service provider to easily add SAML authentication to any of your applications without changing its code.

[[sso-configuration-openig-as-saml-service-provider-for-openam-preparation]]
=== Preparation

[arabic]
. To simplify service deployment, we will use OpenAM and OpenIG's Docker images. Therefore, you must have Docker installed.
. Enter the host names for OpenAM and OpenIG in the `hosts` file. On Windows systems, the hosts file is located in the `C:++\++Windows/System32/drivers/etc/hosts` directory, and on Linux or Mac OS, it is located in `/etc/hosts`.
+
....
127.0.0.1    openam.example.org openig.example.org
....

[[sso-configuration-openig-as-saml-service-provider-for-openam-configuring-openam]]
=== Configuring OpenAM

[[sso-configuration-openig-as-saml-service-provider-for-openam-installing-openam]]
==== Installing OpenAM

Deploy the OpenAM container with the command:

[source,bash]
----
docker run -h openam.example.org -p 8080:8080 --name openam openidentityplatform/openam
----

And perform the initial configuration:

[source,bash]
----
docker exec -w '/usr/openam/ssoconfiguratortools' openam bash -c \
'echo "ACCEPT_LICENSES=true
SERVER_URL=http://openam.example.org:8080
DEPLOYMENT_URI=/$OPENAM_PATH
BASE_DIR=$OPENAM_DATA_DIR
locale=en_US
PLATFORM_LOCALE=en_US
AM_ENC_KEY=
ADMIN_PWD=passw0rd
AMLDAPUSERPASSWD=p@passw0rd
COOKIE_DOMAIN=example.org
ACCEPT_LICENSES=true
DATA_STORE=embedded
DIRECTORY_SSL=SIMPLE
DIRECTORY_SERVER=openam.example.org
DIRECTORY_PORT=50389
DIRECTORY_ADMIN_PORT=4444
DIRECTORY_JMX_PORT=1689
ROOT_SUFFIX=dc=openam,dc=example,dc=org
DS_DIRMGRDN=cn=Directory Manager
DS_DIRMGRPASSWD=passw0rd" > conf.file && java -jar openam-configurator-tool*.jar --file conf.file'
----

[[sso-configuration-openig-as-saml-service-provider-for-openam-openam-identity-provider-setup]]
==== OpenAM Identity Provider Setup

[arabic]
. Access the administrator console via the link http://openam.example.org:8080/openam[http://openam.example.org:8080/openam]. Use the login `amadmin` and password `passw0rd`.
. Select Top Level Realm
. Go to *Create SAMLv2 Providers* → *Create Hosted Identity Provider*
. Set Metadata Name: `openam`
. In the Signing Key setting, select `test`
. Enter the name of the Circle of Trust, for example, `cot`
. In the Attribute Mapping section, add the mapping uid → uid, mail → mail
. Click *Configure*

[[sso-configuration-openig-as-saml-service-provider-for-openam-openam-fedlet-configuration]]
==== OpenAM Fedlet Configuration

[arabic]
. Open the administrator console
. Select Top Level Realm
. Go to *Create Fedlet Configuration*
. Enter the fedlet name in the Name field, for example, openig.
. Set the *Destination URL of the Service Provider which will include the Fedlet* to the URL that points to OpenIG: `http://openig.example.org:8081/saml`
. In the Attribute Mapping section, add the mapping uid → uid, mail → mail
. Click *Create*
+
The Fedlet settings will be saved in the container in the directory `/usr/openam/config/myfedlets/openig/Fedlet.zip`.
+
Copy the settings to the host machine using the command:
+
[source,bash]
----
docker cp openam:/usr/openam/config/myfedlets/openig/Fedlet.zip .
----

[[sso-configuration-openig-as-saml-service-provider-for-openam-preparing-a-test-user]]
==== Preparing a test user

[arabic]
. Open the administrator console
. Select Top Level Realm
. In the left pane, select Subjects
. In the list of accounts, open the `demo` account
. In the Email Address field, enter `demo@example.org` or another valid email
. Click *Save*

[[sso-configuration-openig-as-saml-service-provider-for-openam-openig-setup]]
=== OpenIG Setup

[[sso-configuration-openig-as-saml-service-provider-for-openam-preparing-openig-configuration-files]]
==== Preparing OpenIG Configuration Files

[arabic]
. Create a directory for OpenIG configuration files `openig-saml`
. Add a directory `config` to it
. In the `config` directory, create the files `admin.json` and `config.json`:
+
`admin.json`:
+
[source,json]
----
{
  "prefix" : "openig",
  "mode": "PRODUCTION"
}
----
+
`config.json`:
+
[source,json]
----
{
  "heap": [
    {
      "name": "JwtSession",
      "type": "JwtSession"
    },
    {
      "name": "capture",
      "type": "CaptureDecorator",
      "config": {
        "captureEntity": true,
        "_captureContext": true
      }
    }
  ],
  "handler": {
    "type": "Chain",
    "config": {
      "filters": [],
      "handler": {
        "type": "Router",
        "name": "_router",
        "capture": "all"
      }
    }
  }
}
----
. Add a directory for routes named `routes` to the `config` directory.
. Add the default route `99-default.json` to the `routes` directory. OpenIG will serve static content on this route and will not require authentication:
+
[source,json]
----
{
  "handler": {
    "type": "DispatchHandler",
    "config": {
      "bindings": [
        {
          "handler": {
            "type": "StaticResponseHandler",
            "config": {
              "status": 200,
              "reason": "OK",
              "entity":
"<!doctype html>
<html>
<head>
  <title>Home</title>
  <meta charset='UTF-8'>
</head>
<body>
  <h1><a href='/app'>Login</a></h1>
</body>
</html>"
            }
          }
        }
      ]
    }
  },
  "session": "JwtSession"
}
----
. Start the OpenIG Docker container with the command. Note the mounted directory `/app-saml`.
+
[source,bash]
----
docker run -h openig.example.org -p 8081:8080 --name openig \
  -v ./app-saml:/usr/local/app-saml:ro \
  -e "CATALINA_OPTS=-Dopenig.base=/usr/local/app-saml" \
  openidentityplatform/openig
----
. Check if the application is working:
+
[source,bash]
----
$ curl -v http://openig.example.org:8081

[[sso-configuration-openig-as-saml-service-provider-for-openam-configuring-saml-fedlet-in-openig]]
==== Configuring SAML Fedlet in OpenIG

[arabic]
. In the `openig-saml` directory, create a directory named `SAML`.
. Copy the contents of the Fedlet.zip archive that you received from OpenAM into this directory.
+
[source,bash]
----
unzip Fedlet.zip
cp conf/* app-saml/SAML/
----
. Create a route for obtaining credentials from SAML assertions `05-saml.json`
+
[source,json]
----
{
 "handler": {
   "type": "SamlFederationHandler",
   "config": {
     "assertionMapping": {
       "uid": "uid",
       "mail": "mail"
     },
     "redirectURI": "/app"
   }
 },
 "condition": "${matches(request.uri.path, '^/saml')}",
 "session": "JwtSession"
}
----
. Create a route for the application requiring SAML authentication `05-app.json`:
+
[source,json]
----
{
  "handler": {
    "type": "DispatchHandler",
    "config": {
      "bindings": [
        {
          "condition": "${empty session.uid}",
          "handler": {
            "type": "StaticResponseHandler",
            "config": {
              "status": 302,
              "reason": "Found",
              "headers": {
                "Location": [
                  "http://openig.example.org:8081/saml/SPInitiatedSSO"
                ]
              }
            }
          }
        },
        {
          "handler": {
          "handler": {
            "type": "StaticResponseHandler",
            "config": {
              "status": 200,
              "reason": "OK",
              "entity":
"<!doctype html>
<html>
<head>
  <title>OpenID Connect Discovery</title>
  <meta charset='UTF-8'>
</head>
<body>
  <h1>User: ${session.uid}, email: ${session.mail} </h1>
</body>
</html>"
            }
          }
        }
        }
      ]
    }
  },
  "condition": "${matches(request.uri.path, '^/app')}",
  "session": "JwtSession"
}
----
. Start the OpenIG container:
+
[source,bash]
----
docker run -h openig.example.org -p 8081:8080 --name openig \
  -v ./app-saml:/usr/local/app-saml:ro \
  -e “CATALINA_OPTS=-Dopenig.base=/usr/local/app-saml” \
  openidentityplatform/openig
----

[[sso-configuration-openig-as-saml-service-provider-for-openam-conclusion]]
=== Conclusion.

We have successfully configured OpenIG as a Service Provider and implemented SAML 2.0 authentication via OpenAM. You can now use this approach to secure any applications in your infrastructure. The next step could be to configure Log Out.
