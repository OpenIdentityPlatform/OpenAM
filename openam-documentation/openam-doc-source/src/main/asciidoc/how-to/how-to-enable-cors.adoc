[#how-to-enable-cors]
== How to Enable CORS

Open the administrator console. In the top menu, select Configure → Global Services.

image:images/how-to/openam-spa-oauth2/4-global-services.png[OpenAM Global Services]

Next, go to CORS Settings and enable CORS support

image:images/how-to/openam-spa-oauth2/5-cors-settings.png[OpenAM CORS settings]

Pres the `Save Changes` button.
