[#how-to-disable-xui-by-default]
== How to disable XUI by default

[[how-to-disable-xui-by-default-legacy-ui]]
=== Legacy UI

[[how-to-disable-xui-by-default-for-one-instance-in-cluster]]
==== For one instance in cluster

Goto Configuration ++>++ Servers and Sites ++>++ Default Server Settings ++>++ Advanced and add:

....
XUI.enable=false
....

or change java system property:

[source,bash]
----
-DXUI.enable=false
----

[[how-to-disable-xui-by-default-for-all-instances-in-cluster]]
==== For all instances in cluster

Goto Configuration ++>++ Servers and Sites ++>++ Select server ++>++ Advanced and add:

....
XUI.enable=false
....

[[how-to-disable-xui-by-default-xui-interface]]
=== XUI Interface

[[how-to-disable-xui-by-default-for-one-instance-in-cluster-1]]
==== For one instance in cluster

Goto Deployment ++>++ Servers ++>++ Choose server ++>++ Advanced and add:

....
XUI.enable=false
....

[[how-to-disable-xui-by-default-for-all-instances-in-cluster-1]]
==== For all instances in cluster

Goto Configure ++>++ Server Defaults ++>++ Advanced and add:

....
XUI.enable=false
....
