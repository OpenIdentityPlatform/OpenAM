== How to disable XUI by default

ifdef::env-site[]
anchor:how-to-disable-xui-by-default[]
endif::[]

[[how-to-disable-xui-by-default-legacy-ui]]
=== Legacy UI

The `XUI.enable` override applies to both the end-user interface and the administrative console.

[[how-to-disable-xui-by-default-for-one-instance-in-cluster]]
==== For one instance in cluster

Go to Configuration > Servers and Sites, select the server by name, and add the property under Advanced.

....
XUI.enable=false
....

You can also set the Java system property for the node's JVM.

[source,bash]
----
-DXUI.enable=false
----

[[how-to-disable-xui-by-default-for-all-instances-in-cluster]]
==== For all instances in cluster

Go to Configuration > Servers and Sites > Default Server Settings > Advanced and add the property. Check for per-server overrides.

....
XUI.enable=false
....

[[how-to-disable-xui-by-default-xui-interface]]
=== XUI Interface

[[how-to-disable-xui-by-default-for-one-instance-in-cluster-1]]
==== For one instance in cluster

Go to Deployment > Servers > __Server Name__ > Advanced and add the property.

....
XUI.enable=false
....

[[how-to-disable-xui-by-default-for-all-instances-in-cluster-1]]
==== For all instances in cluster

Go to Configure > Server Defaults > Advanced and add the property. Check for per-server overrides.

....
XUI.enable=false
....
