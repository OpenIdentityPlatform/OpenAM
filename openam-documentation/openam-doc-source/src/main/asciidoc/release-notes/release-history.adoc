== Community Release History

ifdef::env-site[]
anchor:release-history[]
endif::[]

This overview covers the published community release records through 16.1.4. Dates are the GitHub publication dates, in UTC. The table summarizes selected changes; use each release record for the complete list and assets. Early records contain only commit ranges, so their summaries are drawn from the linked source comparisons. Gaps in version numbers reflect the published records and are not filled with inferred releases.

Review the https://github.com/OpenIdentityPlatform/OpenAM/security/advisories[published security advisories] alongside the history: a fix in an older release is not a guarantee against subsequent bypasses or newly disclosed vulnerabilities. In particular, later 16.1.x releases extend earlier SSRF, script sandbox, deserialization, and PKCE fixes.
