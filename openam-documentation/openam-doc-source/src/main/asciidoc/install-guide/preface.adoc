== Preface

Use this guide to install OpenAM for access management and federation. Review the xref:../release-notes/requirements-and-upgrade.adoc[release requirements] before choosing a container and Java version.

[#who-should-use]
=== Who Should Use This Guide

For an evaluation, follow xref:../getting-started/index.adoc[Getting Started With OpenAM] to run a local instance and protect a test resource.

For a new deployment, start with xref:chap-prepare-install.adoc#before-production-installation[Before a Production Installation], then follow xref:chap-install-core.adoc[Installing OpenAM Core Services]. For a site with several OpenAM servers, also follow xref:chap-install-multiple.adoc[Installation Considerations for Multiple Servers].

For an existing deployment, follow the xref:../upgrade-guide/index.adoc[Upgrade Guide] for the target release.
